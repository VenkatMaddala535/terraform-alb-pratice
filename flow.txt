Resource	        Required references
ALB_SG	            VPC ID
ALB	ALB             SG ID + Subnet IDs
ALB_TG	            VPC ID
ALB_TG_ASSOCIATION	ALB_TG ARN + EC2 ID
ALB_LISTENER	    ALB ARN + ALB_TG ARN

Resource	    Simple purpose
ALB SG	        Who can access ALB?
ALB	            Who distributes traffic?
ALB TG	        Where should traffic go?
ALB TGA	        Which EC2 instances belong to TG?
ALB Listener	On which port to listen and where to forward?

ALB SG  -> Controls who can access ALB.

ALB -> Receives incoming traffic.

ALB TG  -> Defines backend targets and health checks.

ALB TGA -> Registers EC2 instances with Target Group.

ALB Listener    -> Listens on a port and decides what action to perform.
